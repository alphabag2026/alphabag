# AlphaBag 온체인 포인트 계약 초안

이 디렉터리의 Solidity 파일은 **ABP 온체인 포인트 토큰**과 **USDT P2P 에스크로 시장**의 구현 후보입니다. 소스가 존재하거나 컴파일을 통과했다는 사실은 보안감사·법률검토·메인넷 배포 승인을 의미하지 않습니다.

## 안전한 출시 순서

1. BSC, Ethereum Sepolia, Nile(TRON) 등 테스트 네트워크에서 별도 테스트를 실행합니다.
2. 단위·통합·퍼징 테스트와 독립된 스마트 컨트랙트 보안감사를 완료합니다.
3. `DEFAULT_ADMIN_ROLE`, `MINTER_ROLE`, `PAUSER_ROLE`, `FEE_MANAGER_ROLE`를 개인 EOA가 아닌 최소 2-of-3 멀티시그에 할당합니다.
4. 감사 보고서의 계약 바이트코드·배포 주소·컴파일러 버전·생성자 인자를 관리자 화면에 기록합니다.
5. 체인 이벤트 인덱서가 `OrderCreated`, `OrderFilled`, `OrderCancelled`, `Transfer` 이벤트를 최소 확정 수 이후에만 DB에 반영하도록 활성화합니다.
6. 소액 한도와 긴급 일시정지부터 시작하고, 모니터링·사고 대응·이용자 고지 체계를 운영합니다.

## 현재 범위

- `ABPPoint.sol`: 18자리 소수점 ERC-20, 발행 상한, 역할 기반 발행·일시정지, EIP-2612 Permit.
- `ABPMarketEscrow.sol`: 판매자가 ABP를 예치하고 구매자가 USDT 승인 후 원자적으로 체결하는 EVM용 에스크로.
- `ABPHybridCheckout.sol`: 플랜별 정책 버전 기준으로 투자금의 70~95% USDT와 5~30% ABP를 체인에서 산정·수납하는 EVM 결제 계약.
- TRON(TRC-20)은 별도 언어·배포 도구·감사 범위를 요구하므로, EVM 계약을 그대로 복사해 배포하지 않습니다.

> 메인넷 배포, 역할 변경, 민팅, 수수료 설정, 실자금 전송은 운영 책임자가 별도의 승인 절차를 거쳐 수행해야 합니다.
